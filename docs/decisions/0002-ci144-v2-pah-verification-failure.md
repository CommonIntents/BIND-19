# ADR-0023：CI-144 v2.0 PAH 第二层验证失败处理（致命边界条件）

## 状态
**Draft**（2026-08-29，Alpha 实现期间待锁定）

## 上下文
PAH 双层安全架构中，第一层 64-bit 快速校验和第二层 512-bit 完整验证的失败处理必须明确区分。这是致命边界条件，必须写入规则 5 的伪代码分支中。

## 决策（初步定案，Alpha 编码前最终确认）
- **第一层 64-bit 验证失败**：直接拒绝帧（规则 5 已定义，不可动摇）
- **第一层通过但第二层 512-bit 验证失败**：不拒绝帧（避免实时阻塞），但触发异步告警 + 标记会话为"可疑"，累积阈值后吊销密钥
- 累积阈值：连续 3 次第二层验证失败触发密钥吊销（Alpha 编码前最终确认数值）
- 理由：第一层已提供基础防伪，第二层是事后追责；第一层失败意味着明确的伪造，第二层失败可能是噪声或边缘情况

## 后果
- 规则 5 需补充伪代码分支，明确区分第一层/第二层失败处理
- 需实现异步告警机制和会话"可疑"标记
- 需定义密钥吊销的触发阈值和流程（关联 ADR-0024）
