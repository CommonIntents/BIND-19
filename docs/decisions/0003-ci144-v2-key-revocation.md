# ADR-0024：CI-144 v2.0 密钥吊销流程（Anaphase 发起 + BIND-19 广播）

## 状态
**Draft**（2026-08-29，Alpha 实现期间待锁定）

## 上下文
PAH 第二层验证发现伪造后，需触发密钥吊销机制。吊销流程的发起者、传播方式、生效时间需明确定义。

## 决策（初步定案，Alpha 编码前最终确认）
- **发起者**：Anaphase（编排中枢）发起密钥吊销
- **传播方式**：通过 BIND-19 控制帧广播至所有 Tuck
- **生效时间**：≤1 秒（尽力而为目标）
- **兜底机制**：广播超时未达则降级为 CATASTROPHIC 物理硬阻断（使用 PAL 的 CATASTROPHIC 硬覆盖紧急阻断）
- 理由：Anaphase 作为编排中枢发起吊销合理；BIND-19 控制帧广播高效；≤1 秒是尽力而为目标，关键紧急场景可用 CATASTROPHIC 硬覆盖兜底

## 后果
- 需实现 BIND-19 密钥吊销控制帧格式
- 需实现广播可靠性机制（确认/重试）
- 需定义 CATASTROPHIC 硬覆盖作为兜底的触发条件
