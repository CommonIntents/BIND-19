# ADR-0027：CI-144 v2.0 主密钥管理（非本协议范围，接口定义）

## 状态
**Draft**（2026-08-29，Alpha 实现期间待锁定）

## 上下文
CI-144 v2.0 协议使用主密钥加密保护新会话密钥（KEY_ROTATION 帧中的 new_key_encrypted）。主密钥本身的管理流程超出 CI-144 协议范围，但协议需定义主密钥的接口（加密算法）。

## 决策（初步定案，Alpha 编码前最终确认）
- **主密钥持有**：由 Helix-Mind 的 HSM/TPM 持有
- **轮换周期**：90 天
- **分发方式**：通过离线安全通道分发（非本协议范围）
- **协议接口**：CI-144 只需定义 new_key_encrypted 的加密算法（AES-256-GCM 由主密钥加密），不需定义主密钥管理流程
- 理由：主密钥管理确实超出 CI-144 协议范围，属于 Helix 生态的安全管理范畴；CI-144 只需定义接口

## 后果
- CI-144 协议需定义 new_key_encrypted 的加密算法（AES-256-GCM）
- 主密钥管理流程由 Helix-Mind 侧定义（可能需要独立的 ADR 或设计文档）
- 主密钥轮换时需确保所有参与方同步更新（离线安全通道）
