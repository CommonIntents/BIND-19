# ADR-0022：CI-144 v2.0 PAH 第二层签名位置（INTENT-7 载荷头部扩展）

## 状态
**Draft**（2026-08-29，Alpha 实现期间待锁定）

## 上下文
CI-144 v2.0 确立 PAH 双层安全架构：第一层 64-bit 快速校验（PAL 头部，Tuck 硬实时决策），第二层 512-bit 完整验证（载荷解密后，Helix-Mind/云端审计）。第二层签名在载荷中的具体位置需明确定义。

## 决策（初步定案，Alpha 编码前最终确认）
- 第二层签名放在 **INTENT-7 v2.0 载荷的头部扩展区**，格式为：`[512-bit Sig] + [Varint Payload-Len] + [Payload]`
- 理由：签名针对载荷内容，放在载荷头部可在解密后立即验证，不需要额外的解析步骤
- 需定义 INTENT-7 v2.0 的载荷头部扩展格式（与 v1.0 向后兼容）

## 后果
- INTENT-7 协议需升级至 v2.0，定义载荷头部扩展格式
- 接收端解密后需先验证第二层签名，再处理载荷内容
- 向后兼容：v1.0 载荷无签名扩展，v2.0 接收端需识别版本标志
