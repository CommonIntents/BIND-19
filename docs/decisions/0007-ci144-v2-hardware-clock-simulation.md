# ADR-0028：CI-144 v2.0 审计日志硬件时钟软件模拟

## 状态
**Draft**（2026-08-29，Alpha 实现期间待锁定）

## 上下文
CI-144 v2.0 规范要求审计日志附带"硬件时钟"（规则 6 Replay-Enable=0 审计标记）。但在纯软件实现阶段（Helix-Mind + 软件 Tuck），没有物理硬件时钟来源。

## 决策（初步定案，Alpha 编码前最终确认）
- 软件模拟阶段使用 `CLOCK_REALTIME` + 单调计数器合成时间戳
- 防回滚标记：存储上次时间戳，若检测到时间回滚（系统时间调整），则触发告警并在审计日志中标记 `CLOCK_ROLLBACK=1`
- 合成格式：`[CLOCK_REALTIME 纳秒] + [单调计数器 64-bit]`，确保即使 CLOCK_REALTIME 回滚，单调计数器仍可排序
- 硬件阶段替换为硬件 RTC + 安全计数器，接口不变

## 后果
- 审计日志时间戳在软件阶段是"合成时间"，非严格物理时间
- 防回滚机制可检测系统时间调整，但无法防止攻击者同时修改系统时间和审计日志（需 HMAC 链保护）
- 单调计数器需持久化（进程重启后继续递增）
